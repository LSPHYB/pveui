# 三、通知模块

## 3.1 模块概述

**模块名称**：智能通知推送模块 (Notification Module)

**功能描述**：

- 模板化通知：支持变量替换的通知模板
- 多渠道推送：站内信、邮件、短信（可选）
- 定时发送：支持预约发送时间
- 个性化订阅：用户自定义接收偏好
- 批量推送：支持按角色、组织批量发送
- 发送日志：完整的发送记录和失败重试

**核心价值**：

- 及时通知：实验发布、截止提醒、批改完成
- 减少遗漏：重要消息多渠道触达
- 提升体验：个性化推送，减少打扰
- 可追溯性：完整的发送日志

**技术栈**：

- 后端：Django + Celery
- 消息队列：Redis
- 邮件：SMTP / SendGrid
- 短信：阿里云SMS / Twilio（可选）
- WebSocket：实时推送

## 3.2 实体设计

### 3.2.1 通知模板实体 (NotificationTemplate)

**实体说明**：可复用的通知模板

**字段定义**：

| 字段名           | 类型         | 必填 | 说明             | 示例值                               |
| ---------------- | ------------ | ---- | ---------------- | ------------------------------------ |
| id               | bigint       | 是   | 主键             | 1                                    |
| name             | varchar(100) | 是   | 模板名称         | "实验发布通知"                       |
| code             | varchar(50)  | 是   | 模板代码（唯一） | "EXPERIMENT_PUBLISHED"               |
| category         | varchar(50)  | 是   | 分类             | system / course / vm / announcement  |
| description      | text         | 否   | 模板描述         | "当教师发布新实验时通知学生"         |
| title_template   | varchar(255) | 是   | 标题模板         | "新实验已发布：{{experiment_title}}" |
| content_template | text         | 是   | 内容模板         | "《{{experiment_title}}》已发布..."  |
| content_type     | varchar(20)  | 否   | 内容类型         | text / html / markdown               |
| channels         | json         | 是   | 推送渠道         | ["site", "email"]                    |
| priority         | varchar(20)  | 否   | 优先级           | low / normal / high / urgent         |
| is_realtime      | boolean      | 否   | 是否实时推送     | true                                 |
| variables        | json         | 否   | 变量列表及说明   | {"experiment_title": "实验标题"}     |
| is_active        | boolean      | 是   | 是否启用         | true                                 |
| created_at       | datetime     | 是   | 创建时间         | 自动生成                             |

**业务规则**：

- `code` 全局唯一，用于代码中引用模板
- 模板支持变量替换：`{{variable_name}}`
- 可预览渲染后的效果

**模板示例**：

```json
{
  "code": "EXPERIMENT_PUBLISHED",
  "title_template": "新实验已发布：{{experiment_title}}",
  "content_template": "尊敬的{{student_name}}，\n\n《{{experiment_title}}》实验已发布。\n\n截止时间：{{end_time}}\n预计完成时长：{{estimated_hours}}小时\n\n请及时完成实验并提交报告。\n\n点击查看：{{experiment_url}}",
  "variables": {
    "student_name": "学生姓名",
    "experiment_title": "实验标题",
    "end_time": "截止时间",
    "estimated_hours": "预计时长",
    "experiment_url": "实验链接"
  }
}
```

**索引设计**：

```sql
UNIQUE INDEX code (code)
INDEX idx_category_active (category, is_active)
```

### 3.2.2 通知记录实体 (NotificationRecord)

**实体说明**：具体的通知发送记录

**字段定义**：

| 字段名            | 类型         | 必填 | 说明                  | 示例值                            |
| ----------------- | ------------ | ---- | --------------------- | --------------------------------- |
| id                | bigint       | 是   | 主键                  | 1                                 |
| title             | varchar(255) | 是   | 通知标题              | "新实验已发布：Linux用户管理"     |
| content           | text         | 是   | 通知内容              | "《Linux用户管理》已发布..."      |
| content_type      | varchar(20)  | 否   | 内容类型              | text / html / markdown            |
| template_id       | bigint       | 否   | 使用的模板ID          | 1                                 |
| category          | varchar(50)  | 是   | 分类                  | course                            |
| priority          | varchar(20)  | 否   | 优先级                | normal                            |
| notification_type | varchar(50)  | 是   | 通知类型              | experiment_published              |
| sender_id         | int          | 否   | 发送者ID（NULL=系统） | 5                                 |
| sender_type       | varchar(20)  | 否   | 发送者类型            | user / system                     |
| related_type      | varchar(50)  | 否   | 关联对象类型          | experiment                        |
| related_id        | varchar(100) | 否   | 关联对象ID            | "1"                               |
| related_data      | json         | 否   | 关联数据快照          | {"experiment_title": "..."}       |
| channels          | json         | 是   | 推送渠道              | ["site", "email"]                 |
| scheduled_at      | datetime     | 否   | 定时发送时间          | NULL（立即）                      |
| status            | varchar(20)  | 否   | 状态                  | pending / sending / sent / failed |
| sent_at           | datetime     | 否   | 实际发送时间          | 2024-03-10 16:00:00               |
| error_message     | text         | 否   | 错误信息              | NULL                              |
| retry_count       | int          | 否   | 重试次数              | 0                                 |
| attachments       | json         | 否   | 附件列表              | [...]                             |
| created_at        | datetime     | 是   | 创建时间              | 自动生成                          |

**业务规则**：

- 创建后立即推送（`scheduled_at=NULL`）或定时推送
- 多渠道并行发送，独立追踪状态
- 发送失败自动重试（最多3次）

**通知类型示例**：

- `experiment_published`：实验发布
- `experiment_deadline`：截止提醒
- `experiment_graded`：批改完成
- `comment_reply`：评论回复
- `vm_status_change`：虚拟机状态变更
- `system_announcement`：系统公告

**索引设计**：

```sql
INDEX idx_category_created (category, created_at)
INDEX idx_type_status (notification_type, status)
INDEX idx_scheduled (scheduled_at, status)
INDEX idx_related (related_type, related_id)
```

### 3.2.3 通知接收记录实体 (NotificationRecipient)

**实体说明**：通知与接收者的多对多关系

**字段定义**：

| 字段名          | 类型        | 必填 | 说明         | 示例值                     |
| --------------- | ----------- | ---- | ------------ | -------------------------- |
| id              | bigint      | 是   | 主键         | 1                          |
| notification_id | bigint      | 是   | 通知ID       | 1                          |
| recipient_id    | int         | 是   | 接收者用户ID | 101                        |
| recipient_type  | varchar(20) | 否   | 接收者类型   | user / role / organization |
| is_read         | boolean     | 是   | 是否已读     | false                      |
| read_at         | datetime    | 否   | 阅读时间     | NULL                       |
| site_status     | varchar(20) | 否   | 站内信状态   | sent / failed              |
| email_status    | varchar(20) | 否   | 邮件状态     | sent / failed              |
| sms_status      | varchar(20) | 否   | 短信状态     | NULL                       |
| is_pinned       | boolean     | 否   | 是否置顶     | false                      |
| is_archived     | boolean     | 否   | 是否归档 | false |
| archived_at | datetime | 否 | 归档时间 | NULL |
| error_details | json | 否 | 各渠道错误详情 | {...} |
| created_at | datetime | 是 | 创建时间 | 自动生成 |

**业务规则**：
- 一条通知可以有多个接收者
- 每个接收者独立追踪阅读状态
- 每个渠道独立追踪发送状态

**索引设计**：
```sql
UNIQUE INDEX unique_notification_recipient (notification_id, recipient_id)
INDEX idx_recipient_read (recipient_id, is_read, created_at)
INDEX idx_recipient_archived (recipient_id, is_archived)
```

### 3.2.4 通知订阅配置实体 (NotificationSubscription)

**实体说明**：用户个性化订阅设置

**字段定义**：

| 字段名 | 类型 | 必填 | 说明 | 示例值 |
|--------|------|------|------|--------|
| id | bigint | 是 | 主键 | 1 |
| user_id | int | 是 | 用户ID | 101 |
| notification_type | varchar(50) | 是 | 通知类型 | experiment_published |
| enable_site | boolean | 否 | 启用站内信 | true |
| enable_email | boolean | 否 | 启用邮件 | true |
| enable_sms | boolean | 否 | 启用短信 | false |
| quiet_hours_start | time | 否 | 免打扰开始时间 | 22:00:00 |
| quiet_hours_end | time | 否 | 免打扰结束时间 | 08:00:00 |
| is_enabled | boolean | 是 | 是否启用该类型通知 | true |
| custom_config | json | 否 | 自定义配置 | {...} |
| created_at | datetime | 是 | 创建时间 | 自动生成 |

**业务规则**：
- 用户首次使用时创建默认配置
- 免打扰时段内不发送通知（紧急通知除外）
- 用户可自由开关各类通知

**索引设计**：
```sql
UNIQUE INDEX unique_user_type (user_id, notification_type)
```

### 3.2.5 通知发送日志实体 (NotificationSendLog)

**实体说明**：详细的发送日志，用于问题排查

**字段定义**：

| 字段名 | 类型 | 必填 | 说明 | 示例值 |
|--------|------|------|------|--------|
| id | bigint | 是 | 主键 | 1 |
| notification_id | bigint | 是 | 通知ID | 1 |
| recipient_id | int | 是 | 接收者ID | 101 |
| channel | varchar(20) | 是 | 发送渠道 | site / email / sms |
| status | varchar(20) | 是 | 发送状态 | success / failed |
| request_data | json | 否 | 请求数据 | {...} |
| response_data | json | 否 | 响应数据 | {...} |
| error_message | text | 否 | 错误信息 | NULL |
| retry_of_log_id | bigint | 否 | 重试的原日志ID | NULL |
| created_at | datetime | 是 | 创建时间 | 自动生成 |

**业务规则**：
- 每次发送尝试都记录日志
- 重试时关联原日志ID
- 保留7天后归档

**索引设计**：
```sql
INDEX idx_notification_channel (notification_id, channel)
INDEX idx_created (created_at)
```

## 3.3 后端API设计

### 3.3.1 通知接收API（学生/教师）

**基础路径**：`/api/v1/notifications/`

#### 1) 获取我的通知列表

```http
GET /api/v1/notifications/my/
```

**请求参数**：
```json
{
  "page": 1,
  "page_size": 20,
  "is_read": false,              // 可选：筛选未读
  "category": "course",          // 可选
  "is_archived": false           // 可选：不包括已归档
}
```

**响应示例**：
```json
{
  "code": 200,
  "data": {
    "total": 8,
    "unread_count": 3,
    "results": [
      {
        "id": 1,
        "title": "新实验已发布：Linux用户管理",
        "content": "《Linux用户管理》实验已发布...",
        "category": "course",
        "priority": "normal",
        "notification_type": "experiment_published",
        "sender": {
          "id": 5,
          "name": "张老师",
          "avatar": "/media/avatars/5.jpg"
        },
        "related_data": {
          "experiment_id": 1,
          "experiment_url": "/student/experiments/1"
        },
        "is_read": false,
        "is_pinned": false,
        "created_at": "2024-03-10T16:00:00Z"
      }
    ]
  }
}
```

#### 2) 获取未读数量

```http
GET /api/v1/notifications/unread_count/
```

**响应示例**：
```json
{
  "code": 200,
  "data": {
    "total": 3,
    "by_category": {
      "course": 2,
      "system": 1
    }
  }
}
```

#### 3) 标记为已读

```http
POST /api/v1/notifications/{id}/mark_read/
```

**响应示例**：
```json
{
  "code": 200,
  "message": "已标记为已读",
  "data": {
    "is_read": true,
    "read_at": "2024-03-10T17:00:00Z"
  }
}
```

#### 4) 批量标记已读

```http
POST /api/v1/notifications/mark_all_read/
```

**请求体**：
```json
{
  "category": "course"    // 可选：只标记特定分类
}
```

#### 5) 置顶/取消置顶

```http
POST /api/v1/notifications/{id}/pin/
DELETE /api/v1/notifications/{id}/pin/
```

#### 6) 归档通知

```http
POST /api/v1/notifications/{id}/archive/
```

#### 7) 删除通知

```http
DELETE /api/v1/notifications/{id}/
```

## 3.4 前端设计

### 3.4.1 通知中心页面

**路由**：`/notifications`

**页面布局**：

```vue
<template>
  <div class="notification-center">
    <a-card title="通知中心">
      <template #extra>
        <a-space>
          <a-button @click="markAllRead">
            <icon-check-circle /> 全部已读
          </a-button>
          <a-button @click="showSettings">
            <icon-settings /> 设置
          </a-button>
        </a-space>
      </template>
      
      <!-- 筛选标签 -->
      <a-tabs v-model:active-key="activeTab" @change="handleTabChange">
        <a-tab-pane key="all" title="全部">
          <template #title>
            全部
            <a-badge v-if="unreadCount > 0" :count="unreadCount" />
          </template>
        </a-tab-pane>
        <a-tab-pane key="course" title="课程通知" />
        <a-tab-pane key="system" title="系统通知" />
        <a-tab-pane key="announcement" title="公告" />
      </a-tabs>
      
      <!-- 通知列表 -->
      <a-list :data="notifications" :loading="loading">
        <template #item="{ item }">
          <div 
            :class="['notification-item', { unread: !item.is_read, pinned: item.is_pinned }]"
            @click="handleNotificationClick(item)"
          >
            <!-- 左侧图标 -->
            <div class="notification-icon">
              <a-badge :dot="!item.is_read" :offset="[-5, 5]">
                <icon-notification v-if="item.priority === 'high'" style="color: #f53f3f" />
                <icon-info-circle v-else-if="item.category === 'system'" style="color: #165dff" />
                <icon-book v-else-if="item.category === 'course'" style="color: #00b42a" />
                <icon-sound v-else style="color: #ff7d00" />
              </a-badge>
            </div>
            
            <!-- 内容区 -->
            <div class="notification-content">
              <div class="notification-header">
                <h4>{{ item.title }}</h4>
                <a-tag v-if="item.is_pinned" color="arcoblue" size="small">置顶</a-tag>
                <a-tag v-if="item.priority === 'high'" color="red" size="small">重要</a-tag>
              </div>
              
              <p class="notification-text">{{ item.content }}</p>
              
              <div class="notification-footer">
                <span class="sender">
                  <a-avatar :size="20" :src="item.sender?.avatar">
                    {{ item.sender?.name?.[0] }}
                  </a-avatar>
                  {{ item.sender?.name || '系统' }}
                </span>
                <span class="time">{{ formatTime(item.created_at) }}</span>
              </div>
            </div>
            
            <!-- 操作按钮 -->
            <div class="notification-actions">
              <a-dropdown>
                <a-button type="text" size="small">
                  <icon-more />
                </a-button>
                <template #content>
                  <a-doption @click.stop="pinNotification(item)">
                    <icon-pushpin />
                    {{ item.is_pinned ? '取消置顶' : '置顶' }}
                  </a-doption>
                  <a-doption @click.stop="archiveNotification(item)">
                    <icon-archive />
                    归档
                  </a-doption>
                  <a-doption @click.stop="deleteNotification(item)">
                    <icon-delete />
                    删除
                  </a-doption>
                </template>
              </a-dropdown>
            </div>
          </div>
        </template>
      </a-list>
      
      <!-- 分页 -->
      <a-pagination
        v-model:current="pagination.page"
        :total="pagination.total"
        :page-size="pagination.page_size"
        @change="loadNotifications"
        style="margin-top: 16px; text-align: right"
      />
    </a-card>
  </div>
</template>

<script setup>
import { ref, onMounted } from 'vue'
import { 
  getNotifications, 
  markAsRead, 
  markAllAsRead,
  pinNotification as pinAPI,
  archiveNotification as archiveAPI,
  deleteNotification as deleteAPI
} from '@/api/notification'

const activeTab = ref('all')
const notifications = ref([])
const loading = ref(false)
const unreadCount = ref(0)

const pagination = ref({
  page: 1,
  page_size: 20,
  total: 0
})

const loadNotifications = async () => {
  try {
    loading.value = true
    const params = {
      page: pagination.value.page,
      page_size: pagination.value.page_size
    }
    
    if (activeTab.value !== 'all') {
      params.category = activeTab.value
    }
    
    const res = await getNotifications(params)
    notifications.value = res.data.results
    pagination.value.total = res.data.total
    unreadCount.value = res.data.unread_count
  } finally {
    loading.value = false
  }
}

const handleNotificationClick = async (item) => {
  // 标记为已读
  if (!item.is_read) {
    await markAsRead(item.id)
    item.is_read = true
```

```python
@shared_task
def send_experiment_published_task(experiment_id, sender_id):
    """异步任务：发送实验发布通知"""
    experiment = CourseExperiment.objects.get(id=experiment_id)
    template = NotificationTemplate.objects.get(code='EXPERIMENT_PUBLISHED')
    
    # 获取接收者（所有学生）
    students = User.objects.filter(groups__name='student')
    
    # 创建通知记录

        title=template.title_template.replace('{{experiment_title}}', experiment.title),
        content=template.content_template.replace('{{experiment_title}}', experiment.title)
                                        .replace('{{end_time}}', str(experiment.end_time))
                                        .replace('{{estimated_hours}}', str(experiment.estimated_hours))
                                        .replace('{{experiment_url}}', f'/student/experiments/{experiment.id}'),
        template_id=template.id,
        category='course',
        notification_type='experiment_published',
        sender_id=sender_id,
        related_type='experiment',
        related_id=str(experiment.id),
        channels=['site', 'email']
    )
    
    # 创建接收记录
    recipients = []
    for student in students:

            user_id=student.id,
            notification_type='experiment_published',
            is_enabled=True
        ).first()
        
        if not subscription:
            continue  # 用户关闭了该类型通知
        
        recipient = NotificationRecipient.objects.create(
            notification_id=notification.id,
            recipient_id=student.id
        )
        recipients.append(recipient)
    
    # 多渠道发送
    for recipient in recipients:
        # 站内信
        if subscription.enable_site:
            send_site_notification.delay(notification.id, recipient.id)
        
        # 邮件
        if subscription.enable_email:
```

```python
@shared_task
def send_email_notification(notification_id, recipient_id):
    """发送邮件通知"""
    try:
        notification = NotificationRecord.objects.get(id=notification_id)
        recipient = User.objects.get(id=recipient_id)
        
        # 发送邮件
        send_mail(
            subject=notification.title,
            message=notification.content,
            from_email=settings.DEFAULT_FROM_EMAIL,
            recipient_list=[recipient.email],
            fail_silently=False
        )
        
        # 更新状态
        NotificationRecipient.objects.filter(
            notification_id=notification_id,
            recipient_id=recipient_id
        ).update(email_status='sent')
        
        # 记录日志
        NotificationSendLog.objects.create(
            notification_id=notification_id,
            recipient_id=recipient_id,
            channel='email',
            status='success'
        )
    except Exception as e:
        logger.error(f"邮件发送失败: {e}")
        # 记录失败并重试
        NotificationSendLog.objects.create(
            notification_id=notification_id,
            recipient_id=recipient_id,
            channel='email',
            status='failed',
            error_message=str(e)
        )
        
        # 重试机制
        recipient_record = NotificationRecipient.objects.get(
            notification_id=notification_id,
            recipient_id=recipient_id
        )
        if recipient_record.retry_count < 3:
            recipient_record.retry_count += 1
            recipient_record.save()
            send_email_notification.apply_async(
                args=[notification_id, recipient_id],
                countdown=60 * (2 ** recipient_record.retry_count)  # 指数退避
```

```python
# notification/consumers.py
from channels.generic.websocket import AsyncJsonWebsocketConsumer

class NotificationConsumer(AsyncJsonWebsocketConsumer):
    async def connect(self):
        self.user_id = self.scope['user'].id
        self.group_name = f'user_{self.user_id}'
        
        # 加入用户组
        await self.channel_layer.group_add(
            self.group_name,
            self.channel_name
        )
        
        await self.accept()
    
    async def disconnect(self, close_code):
        # 离开用户组
        await self.channel_layer.group_discard(
            self.group_name,
            self.channel_name
        )
    
    async def notification_message(self, event):
        """接收到新通知"""
        notification_id = event['notification_id']
        
        # 获取通知详情
        notification = await self.get_notification(notification_id)
        
        # 发送给客户端
        await self.send_json({
            'type': 'new_notification',
            'notification': notification
        })
    
    @database_sync_to_async
    def get_notification(self, notification_id):
        from .models import NotificationRecord
        notification = NotificationRecord.objects.get(id=notification_id)
        return {
            'id': notification.id,
            'title': notification.title,
            'content': notification.content,
            'category': notification.category,
            'created_at': notification.created_at.isoformat()
        }
```

### 3.7.2 免打扰时段处理

```python
def should_send_notification(user_id, notification_type, priority):
    """判断是否应该发送通知"""
    # 紧急通知忽略免打扰
    if priority == 'urgent':
        return True
    
    # 获取用户订阅配置
    subscription = NotificationSubscription.objects.filter(
        user_id=user_id,
        notification_type=notification_type
    ).first()
    
    if not subscription or not subscription.is_enabled:
        return False
    
    # 检查免打扰时段
    if subscription.quiet_hours_start and subscription.quiet_hours_end:
        current_time = timezone.now().time()
        
        if subscription.quiet_hours_start < subscription.quiet_hours_end:
            # 正常时段，如 22:00 - 08:00
            if subscription.quiet_hours_start <= current_time <= subscription.quiet_hours_end:
                return False
        else:
            # 跨天时段，如 22:00 - 08:00
            if current_time >= subscription.quiet_hours_start or current_time <= subscription.quiet_hours_end:
                return False
    
    return True
```
