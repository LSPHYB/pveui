# 一、实验课程模块

## 1.1 模块概述

**模块名称**：实验课程管理模块 (Experiment Management Module)

**功能描述**：

- 教师创建和管理实验课程
- 上传实验指导文档（PDF/Word/Markdown）
- 学生查看实验要求并提交报告
- 支持上传操作截图和录屏
- 教师批改和评分


**核心价值**：

- 完整的教学闭环：发布 → 学习 → 提交 → 批改
- 文档智能检索：支持AI从指导书中提取答案
- 过程可追溯：记录学生实验环境和操作历史

**技术栈**：

- 后端：Django REST Framework
- 前端：Vue 3 + Arco Design
- 文件存储：本地文件系统 / 对象存储
- 文档处理：PyPDF2、python-docx、python-markdown

## 1.2 实体设计

### 1.2.1 实验课程实体 (CourseExperiment)

**实体说明**：代表一次完整的实验任务

**字段定义**：

| 字段名                  | 类型         | 必填 | 说明                 | 示例值                              |
| ----------------------- | ------------ | ---- | -------------------- | ----------------------------------- |
| id                      | bigint       | 是   | 主键                 | 1                                   |
| title                   | varchar(200) | 是   | 实验标题             | "Linux用户和权限管理实验"           |
| course_code             | varchar(50)  | 否   | 课程代码             | "CS101-EXP02"                       |
| description             | text         | 否   | 实验描述             | "通过实践掌握Linux用户管理..."      |
| objectives              | json         | 否   | 实验目标列表         | ["掌握useradd命令", "理解文件权限"] |
| category                | varchar(50)  | 是   | 分类                 | linux / network / virtualization    |
| difficulty              | varchar(20)  | 否   | 难度                 | easy / medium / hard                |
| estimated_hours         | decimal(4,1) | 否   | 预计完成时长（小时） | 2.0                                 |
| start_time              | datetime     | 是   | 开始时间             | 2024-03-01 00:00:00                 |
| end_time                | datetime     | 是   | 截止时间             | 2024-03-15 23:59:59                 |
| late_submission_allowed | boolean      | 否   | 是否允许迟交         | true                                |
| late_penalty_rate       | decimal(3,2) | 否   | 迟交扣分比例         | 0.10 (扣10%)                        |
| required_resources      | json         | 否   | 所需资源配置         | {"cpu": 2, "memory": 2048}          |
| pve_template_id         | varchar(100) | 否   | 推荐PVE模板ID        | "ubuntu-22.04-template"             |
| total_score             | decimal(5,2) | 否   | 总分                 | 100.00                              |
| scoring_criteria        | json         | 否   | 评分标准             | {"基础操作": 40, "权限设置": 30}    |
| status                  | varchar(20)  | 否   | 状态                 | draft / published / archived        |
| is_active               | boolean      | 是   | 是否启用(上下架)     | true                                |
| teacher_id              | int          | 是   | 任课教师ID           | 5                                   |
| created_at              | datetime     | 是   | 创建时间             | 自动生成                            |
| updated_at              | datetime     | 是   | 更新时间             | 自动更新                            |
| created_by_id           | int          | 是   | 创建者ID             | 5                                   |
| updated_by_id           | int          | 否   | 更新者ID             | 5                                   |
| owner_organization_id   | int          | 否   | 所属组织ID           | 1                                   |
| is_deleted              | boolean      | 是   | 是否已删除           | false                               |
| remark                  | varchar(500) | 否   | 备注                 |                                     |


**字段说明**：

- `is_active`: 控制实验是否上架。`false`表示下架（学生不可见，教师可见），`true`表示上架。
- `is_deleted`: 控制数据是否删除。`true`表示逻辑删除（回收站），不可恢复。

**业务规则**：

- 截止时间必须晚于开始时间
- 迟交扣分比例范围：0.0 ~ 1.0
- 只有状态为 `published` 的实验对学生可见
- 只有状态为 `published` 且当前时间 >= `start_time` 的实验，学生才能进入详情页和提交
- `scoring_criteria` 存储格式：`{"key": score}` (如 `{"基础操作": 40}`)，前端展示需转换为对象数组

**索引设计**：

```sql
INDEX idx_status_time (status, start_time)
INDEX idx_category (category, is_active)
INDEX idx_teacher (teacher_id, created_at)
```

**文档类型说明**：

**索引设计**：

### 1.2.3 学生实验提交实体 (CourseSubmission)

**实体说明**：学生提交的实验报告及评分信息

**字段定义**：

| 字段名            | 类型         | 必填 | 说明                      | 示例值                                   |
| ----------------- | ------------ | ---- | ------------------------- | ---------------------------------------- |
| id                | bigint       | 是   | 主键                      | 1                                        |
| experiment_id     | bigint       | 是   | 实验ID                    | 1                                        |
| student_id        | int          | 是   | 学生ID                    | 101                                      |
| submission_status | varchar(20)  | 是   | 提交状态                  | draft / submitted / graded               |
| submit_time       | datetime     | 否   | 提交时间                  | 2024-03-10 15:30:00                      |
| is_late           | boolean      | 否   | 是否迟交                  | false                                    |
| report_title      | varchar(255) | 否   | 报告标题                  | "Linux用户和权限管理实验报告"            |
| report_content    | text         | 否   | 报告正文（Markdown/HTML） | "# 实验报告\n## 一、实验环境..."         |
| vm_info           | json         | 否   | 使用的虚拟机信息          | {"vmid": 1001, "vm_name": "ubuntu"}      |
| operation_logs    | json         | 否   | 关键操作记录(前端/PVE采集)| [{"cmd": "useradd tom", "time": "..."}]  |
| score             | decimal(5,2) | 否   | 得分                      | 85.00                                    |
| grade_status      | varchar(20)  | 否   | 批改状态                  | pending / completed                      |
| graded_at         | datetime     | 否   | 批改时间                  | 2024-03-11 10:00:00                      |
| graded_by_id      | int          | 否   | 批改教师ID                | 5                                        |
| feedback          | text         | 否   | 教师评语                  | "实验步骤完整，建议..."                  |
| scoring_details   | json         | 否   | 各项得分明细              | {"基础操作": {"score": 38, "total": 40, "comment": "good"}} |
| revision_count    | int          | 否   | 修订次数                  | 3                                        |
| last_auto_save    | datetime     | 否   | 最后自动保存时间          | 2024-03-10 15:25:00                      |
| created_at        | datetime     | 是   | 创建时间                  | 自动生成                                 |
| updated_at        | datetime     | 是   | 更新时间                  | 自动更新                                 |
| created_by_id     | int          | 是   | 创建者ID (学生)           | 101                                      |
| updated_by_id     | int          | 否   | 更新者ID                  | 101                                      |
| is_deleted        | boolean      | 是   | 是否已删除                | false                                    |
| remark            | varchar(500) | 否   | 备注                      |                                          |

**业务规则**：

- 一个学生对一个实验只能有一个提交记录（唯一约束）
- 学生首次进入实验页面时自动创建草稿（`draft`）
- 支持自动保存，避免数据丢失
- 提交后状态变为 `submitted`，不可再编辑
- 被教师退回（`return`）后，状态变回 `draft`，学生可再次编辑并重新提交
- 迟交判断：`submit_time > experiment.end_time`
- 迟交扣分：`final_score = score * (1 - late_penalty_rate)`

**状态流转**：

```
draft (草稿) → submitted (已提交) → graded (已批改)
     ↑__________________|
         (教师退回修改)
```

**索引设计**：

```sql
UNIQUE INDEX unique_experiment_student (experiment_id, student_id)
INDEX idx_student_status (student_id, submission_status)
INDEX idx_experiment_grade (experiment_id, grade_status)
INDEX idx_submit_time (submit_time)
```

<script setup>
import { ref, reactive } from 'vue'
import { useRouter } from 'vue-router'
import { createExperiment, publishExperiment as publishAPI } from '@/api/experiment'
import { Message } from '@arco-design/web-vue'

const router = useRouter()
const currentStep = ref(0)

const form = reactive({
  title: '',
  course_code: '',
  description: '',
  objectives: [''],
  category: 'linux',
  difficulty: 'medium',
  estimated_hours: 2.0,
  start_time: null,
  end_time: null,
  late_submission_allowed: false,
  late_penalty_rate: 0.1,
  total_score: 100,
  scoring_criteria: {
    item1: { name: '基础操作', score: 40 },
    item2: { name: '权限设置', score: 30 },
    item3: { name: '问题回答', score: 30 }
  }
})

const guidebookFiles = ref([])

const addObjective = () => {
  form.objectives.push('')
}

const removeObjective = (index) => {
  form.objectives.splice(index, 1)
}

const handleGuidebookUpload = (fileList) => {
  guidebookFiles.value = fileList
}

const calculateTotalScore = () => {
  return Object.values(form.scoring_criteria).reduce((sum, item) => sum + item.score, 0);
};

const addScoringItem = () => {
  const newKey = `item${Object.keys(form.scoring_criteria).length + 1}`;
  form.scoring_criteria[newKey] = { name: '', score: 0 };
};

const removeScoringItem = (key) => {
  delete form.scoring_criteria[key];
};

const getCategoryLabel = (value) => {
  const categories = {
    linux: 'Linux系统',
    network: '网络技术',
    virtualization: '虚拟化'
  };
  return categories[value] || value;
};

const getDifficultyLabel = (value) => {
  const difficulties = {
    easy: '简单',
    medium: '中等',
    hard: '困难'
  };
  return difficulties[value] || value;
};

const formatDateTime = (date) => {
  if (!date) return '';
  return new Date(date).toLocaleString();
};

const saveDraft = async () => {
  try {
    const payload = { ...form };
    const criteria = {};
    for (const key in form.scoring_criteria) {
      criteria[form.scoring_criteria[key].name] = form.scoring_criteria[key].score;
    }
    payload.scoring_criteria = criteria;

    const res = await createExperiment({ ...payload, status: 'draft' });
    Message.success('草稿保存成功');
    router.push('/teacher/experiments');
  } catch (error) {
    Message.error('保存失败');
  }
};

const publishExperiment = async () => {
  try {
    // 1. 转换评分标准格式
    const payload = { ...form };
    const criteria = {};
    for (const key in form.scoring_criteria) {
      criteria[form.scoring_criteria[key].name] = form.scoring_criteria[key].score;
    }
    payload.scoring_criteria = criteria;

    // 2. 先创建/更新
    const res = await createExperiment(payload);
    // 3. 再调用发布接口

```sql
-- 1. 实验课程表
CREATE TABLE `course_experiment` (
  `id` bigint NOT NULL AUTO_INCREMENT COMMENT '主键',
  `title` varchar(200) NOT NULL COMMENT '实验标题',
  `course_code` varchar(50) DEFAULT NULL COMMENT '课程代码',
  `description` text COMMENT '实验描述',
  `objectives` json DEFAULT NULL COMMENT '实验目标列表',
  `category` varchar(50) NOT NULL COMMENT '分类',
  `difficulty` varchar(20) DEFAULT 'medium' COMMENT '难度',
  `estimated_hours` decimal(4,1) DEFAULT '2.0' COMMENT '预计时长',
  `start_time` datetime NOT NULL COMMENT '开始时间',
  `end_time` datetime NOT NULL COMMENT '截止时间',
  `late_submission_allowed` tinyint(1) DEFAULT '0' COMMENT '允许迟交',
  `late_penalty_rate` decimal(3,2) DEFAULT '0.00' COMMENT '迟交扣分比例',
  `required_resources` json DEFAULT NULL COMMENT '资源配置',
  `pve_template_id` varchar(100) DEFAULT NULL COMMENT 'PVE模板ID',
  `total_score` decimal(5,2) DEFAULT '100.00' COMMENT '总分',
  `scoring_criteria` json DEFAULT NULL COMMENT '评分标准',
  `status` varchar(20) DEFAULT 'draft' COMMENT '状态',
  `is_active` tinyint(1) NOT NULL DEFAULT '1' COMMENT '启用状态',
  `teacher_id` int NOT NULL COMMENT '教师ID',
  `created_at` datetime NOT NULL DEFAULT CURRENT_TIMESTAMP,
  `updated_at` datetime NOT NULL DEFAULT CURRENT_TIMESTAMP ON UPDATE CURRENT_TIMESTAMP,
  `created_by_id` int NOT NULL COMMENT '创建者ID',
  `updated_by_id` int DEFAULT NULL COMMENT '更新者ID',
  `owner_organization_id` int DEFAULT NULL COMMENT '组织ID',
  `is_deleted` tinyint(1) NOT NULL DEFAULT '0' COMMENT '逻辑删除',
  `remark` varchar(500) DEFAULT NULL COMMENT '备注',
  PRIMARY KEY (`id`),
  KEY `idx_status_time` (`status`,`start_time`),
  KEY `idx_category` (`category`,`is_active`),
  KEY `idx_teacher` (`teacher_id`,`created_at`),
  CONSTRAINT `fk_exp_teacher` FOREIGN KEY (`teacher_id`) REFERENCES `auth_user` (`id`),
  CONSTRAINT `fk_exp_creator` FOREIGN KEY (`created_by_id`) REFERENCES `auth_user` (`id`),
  CONSTRAINT `fk_exp_updater` FOREIGN KEY (`updated_by_id`) REFERENCES `auth_user` (`id`)
) ENGINE=InnoDB DEFAULT CHARSET=utf8mb4 COMMENT='实验课程表';

-- 2. 实验指导书表
CREATE TABLE `course_guidebook` (
  `id` bigint NOT NULL AUTO_INCREMENT,

  `file_size` bigint NOT NULL COMMENT '文件大小',
  `file_type` varchar(50) NOT NULL COMMENT '文件扩展名',
  `file_hash` varchar(64) DEFAULT NULL COMMENT 'SHA256哈希',
  `text_content` longtext COMMENT '提取文本',
  `is_indexed` tinyint(1) DEFAULT '0' COMMENT '是否索引',

  `sections` json DEFAULT NULL COMMENT '章节结构',
  `keywords` json DEFAULT NULL COMMENT '关键词',
  `is_public` tinyint(1) DEFAULT '1' COMMENT '是否公开',

### 1.6.1 教师发布实验流程

```
1. 教师创建实验（草稿状态）

   ↓

   ↓

   ↓

   ↓

   ↓
7. 状态变更：draft → published
   ↓
8. 发送通知给所有学生
```

### 1.6.2 学生提交实验流程

```
1. 学生进入实验详情页
   ↓
2. 系统自动创建提交记录（draft状态）
   ↓
3. 学生查看指导书，开始实验
   ↓
4. 编写报告（支持Markdown）
   ↓
5. 上传操作截图/录屏
   ↓

   ↓
7. 学生点击"提交报告"
   ↓
8. 系统检查内容完整性
   ↓
9. 判断是否迟交
   ↓
10. 状态变更：draft → submitted
   ↓
11. 发送通知给教师
```

```
1. 教师查看待批改列表
   ↓
2. 选择一份报告进入批改页面
   ↓
3. 查看学生报告和附件
   ↓

   ↓
5. 系统自动计算总分
   ↓
6. 点击"提交批改"
   ↓
7. 状态变更：grade_status → completed
   ↓

import PyPDF2

def extract_pdf_text(file_path):
    """提取PDF文本内容"""
    text = ""
    with open(file_path, 'rb') as file:
        reader = PyPDF2.PdfReader(file)
        for page in reader.pages:
            text += page.extract_text()
    return text

    """提取Word文档文本"""
    doc = Document(file_path)

    return text

### 1.7.2 自动保存机制

**前端实现**（Vue 3）：

```javascript
// composables/useAutoSave.js
import { ref, watch, onBeforeUnmount } from 'vue'
import { debounce } from 'lodash-es'

export function useAutoSave(saveFunction, interval = 30000) {
  const lastSaveTime = ref(null)
  const isSaving = ref(false)
  
  // 防抖保存
  const debouncedSave = debounce(async () => {
    if (isSaving.value) return
    
    try {
      isSaving.value = true
      await saveFunction()
      lastSaveTime.value = new Date()
    } catch (error) {
      console.error('自动保存失败', error)
    } finally {
      isSaving.value = false
    }
  }, 2000)
  
  // 定时保存
  const timer = setInterval(debouncedSave, interval)
  
  onBeforeUnmount(() => {
    clearInterval(timer)
  })
  
  return {
    lastSaveTime,
    isSaving,
    manualSave: debouncedSave
  }
}
```

### 1.7.3 文件上传处理

**后端API**（Django）：

```python
# experiment/views.py
from rest_framework.decorators import action
from rest_framework.response import Response
from .serializers import AttachmentSerializer

class SubmissionViewSet(viewsets.ModelViewSet):
    
    @action(detail=True, methods=['post'])
    def upload_attachment(self, request, pk=None):
        submission = self.get_object()
        file = request.FILES['file']
        
        # 检查文件大小
        if file.size > 10 * 1024 * 1024:  # 10MB
            return Response({'error': '文件过大'}, status=400)
        
        # 保存文件
        attachment = Attachment.objects.create(
            submission=submission,
            file=file,
            file_name=file.name,
            file_size=file.size,
            file_type=file.name.split('.')[-1].lower(), # 使用扩展名
            file_category=request.data.get('file_category', 'other'),
            uploaded_by=request.user
        )
        
        # 生成缩略图（异步任务）
        if attachment.file_category == 'screenshot':
            generate_thumbnail.delay(attachment.id)
        
        serializer = AttachmentSerializer(attachment)
        return Response(serializer.data, status=201)
```

# experiment/tasks.py
from celery import shared_task
from PIL import Image

@shared_task
def generate_thumbnail(attachment_id):
    """生成图片缩略图"""
    attachment = Attachment.objects.get(id=attachment_id)
    
    img = Image.open(attachment.file.path)
    img.thumbnail((300, 300))
    
    thumb_path = f"thumbnails/{attachment_id}_thumb.jpg"
    img.save(thumb_path)
    
    attachment.thumbnail_path = thumb_path
    attachment.save()
