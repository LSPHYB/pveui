# 一、实验课程模块

## 1.1 模块概述

**模块名称**：实验课程管理模块 (Experiment Management Module)

**功能描述**：

- 教师创建和管理实验课程
- 上传实验指导文档（PDF/Word/Markdown）
- 学生查看实验要求并提交报告
- 支持上传操作截图和录屏
- 教师批改和评分
- 实验讨论和答疑

**核心价值**：

- 完整的教学闭环：发布 → 学习 → 提交 → 批改
- 文档智能检索：支持AI从指导书中提取答案
- 过程可追溯：记录学生实验环境和操作历史

**技术栈**：

- 后端：Django REST Framework
- 前端：Vue 3 + Arco Design
- 文件存储：本地文件系统 / 对象存储
- 文档处理：PyPDF2、python-docx、python-markdown

## 1.2 实体设计

### 1.2.1 实验课程实体 (CourseExperiment)

**实体说明**：代表一次完整的实验任务

**字段定义**：

| 字段名                  | 类型         | 必填 | 说明                 | 示例值                              |
| ----------------------- | ------------ | ---- | -------------------- | ----------------------------------- |
| id                      | bigint       | 是   | 主键                 | 1                                   |
| title                   | varchar(200) | 是   | 实验标题             | "Linux用户和权限管理实验"           |
| course_code             | varchar(50)  | 否   | 课程代码             | "CS101-EXP02"                       |
| description             | text         | 否   | 实验描述             | "通过实践掌握Linux用户管理..."      |
| objectives              | json         | 否   | 实验目标列表         | ["掌握useradd命令", "理解文件权限"] |
| category                | varchar(50)  | 是   | 分类                 | linux / network / virtualization    |
| difficulty              | varchar(20)  | 否   | 难度                 | easy / medium / hard                |
| estimated_hours         | decimal(4,1) | 否   | 预计完成时长（小时） | 2.0                                 |
| start_time              | datetime     | 是   | 开始时间             | 2024-03-01 00:00:00                 |
| end_time                | datetime     | 是   | 截止时间             | 2024-03-15 23:59:59                 |
| late_submission_allowed | boolean      | 否   | 是否允许迟交         | true                                |
| late_penalty_rate       | decimal(3,2) | 否   | 迟交扣分比例         | 0.10 (扣10%)                        |
| required_resources      | json         | 否   | 所需资源配置         | {"cpu": 2, "memory": 2048}          |
| pve_template_id         | varchar(100) | 否   | 推荐PVE模板ID        | "ubuntu-22.04-template"             |
| total_score             | decimal(5,2) | 否   | 总分                 | 100.00                              |
| scoring_criteria        | json         | 否   | 评分标准             | {"基础操作": 40, "权限设置": 30}    |
| auto_grade_enabled      | boolean      | 否   | 是否启用自动评分     | false                               |
| status                  | varchar(20)  | 否   | 状态                 | draft / published / archived        |
| is_active               | boolean      | 是   | 是否启用             | true                                |
| teacher_id              | int          | 是   | 任课教师ID           | 5                                   |
| created_at              | datetime     | 是   | 创建时间             | 自动生成                            |
| updated_at              | datetime     | 是   | 更新时间             | 自动更新                            |

**业务规则**：

- 截止时间必须晚于开始时间
- 迟交扣分比例范围：0.0 ~ 1.0
- 只有状态为 `published` 的实验对学生可见
- 教师只能管理自己创建的实验

**索引设计**：

```sql
INDEX idx_status_time (status, start_time)
INDEX idx_category (category, is_active)
INDEX idx_teacher (teacher_id, created_at)
```

### 1.2.2 实验指导文档实体 (CourseGuidebook)

**实体说明**：教师上传的实验指导书、参考资料、视频教程等

**字段定义**：

| 字段名         | 类型         | 必填 | 说明                         | 示例值                                    |
| -------------- | ------------ | ---- | ---------------------------- | ----------------------------------------- |
| id             | bigint       | 是   | 主键                         | 1                                         |
| experiment_id  | bigint       | 是   | 所属实验ID                   | 1                                         |
| title          | varchar(200) | 是   | 文档标题                     | "Linux用户管理实验指导书"                 |
| doc_type       | varchar(20)  | 是   | 文档类型                     | guide / reference / video                 |
| description    | text         | 否   | 文档描述                     | "详细的实验步骤和要求"                    |
| file_name      | varchar(255) | 是   | 原始文件名                   | "linux-user-management.pdf"               |
| file_path      | varchar(500) | 是   | 文件存储路径                 | "/uploads/experiments/1/..."              |
| file_size      | bigint       | 是   | 文件大小（字节）             | 2457600                                   |
| file_type      | varchar(50)  | 是   | 文件类型                     | pdf / docx / md / mp4                     |
| file_hash      | varchar(64)  | 否   | 文件哈希值                   | MD5/SHA256                                |
| text_content   | text         | 否   | 提取的文本内容（用于AI检索） | "实验目的：掌握..."                       |
| is_indexed     | boolean      | 否   | 是否已建立AI索引             | true                                      |
| index_status   | varchar(20)  | 否   | 索引状态                     | pending / processing / completed / failed |
| sections       | json         | 否   | 章节结构                     | [{"title": "实验目的", "page": 1}]        |
| keywords       | json         | 否   | 关键词列表                   | ["useradd", "chmod", "chown"]             |
| is_public      | boolean      | 否   | 是否对学生公开               | true                                      |
| view_count     | int          | 否   | 查看次数                     | 125                                       |
| download_count | int          | 否   | 下载次数                     | 45                                        |
| created_at     | datetime     | 是   | 创建时间                     | 自动生成                                  |
| updated_at     | datetime     | 是   | 更新时间                     | 自动更新                                  |

**业务规则**：

- 一个实验可以有多个文档（指导书、参考资料等）
- 文件上传后异步处理：提取文本 → 建立索引
- PDF/Word文档自动提取文本，视频文件不处理
- 只有 `is_public=true` 的文档学生可见

**文档类型说明**：

- `guide`：主要的实验指导书
- `reference`：参考资料、扩展阅读
- `video`：视频教程、操作演示

**索引设计**：

```sql
INDEX idx_experiment (experiment_id, doc_type)
INDEX idx_indexed (is_indexed, index_status)
```

### 1.2.3 学生实验提交实体 (CourseSubmission)

**实体说明**：学生提交的实验报告及评分信息

**字段定义**：

| 字段名            | 类型         | 必填 | 说明                      | 示例值                                   |
| ----------------- | ------------ | ---- | ------------------------- | ---------------------------------------- |
| id                | bigint       | 是   | 主键                      | 1                                        |
| experiment_id     | bigint       | 是   | 实验ID                    | 1                                        |
| student_id        | int          | 是   | 学生ID                    | 101                                      |
| submission_status | varchar(20)  | 是   | 提交状态                  | draft / submitted / graded               |
| submit_time       | datetime     | 否   | 提交时间                  | 2024-03-10 15:30:00                      |
| is_late           | boolean      | 否   | 是否迟交                  | false                                    |
| report_title      | varchar(255) | 否   | 报告标题                  | "Linux用户和权限管理实验报告"            |
| report_content    | text         | 否   | 报告正文（Markdown/HTML） | "# 实验报告\n## 一、实验环境..."         |
| vm_info           | json         | 否   | 使用的虚拟机信息          | {"vmid": 1001, "vm_name": "ubuntu"}      |
| operation_logs    | json         | 否   | 关键操作记录              | [{"cmd": "useradd tom", "time": "..."}]  |
| score             | decimal(5,2) | 否   | 得分                      | 85.00                                    |
| grade_status      | varchar(20)  | 否   | 批改状态                  | pending / grading / completed            |
| graded_at         | datetime     | 否   | 批改时间                  | 2024-03-11 10:00:00                      |
| graded_by_id      | int          | 否   | 批改教师ID                | 5                                        |
| feedback          | text         | 否   | 教师评语                  | "实验步骤完整，建议..."                  |
| scoring_details   | json         | 否   | 各项得分明细              | {"基础操作": {"score": 38, "total": 40}} |
| revision_count    | int          | 否   | 修订次数                  | 3                                        |
| last_auto_save    | datetime     | 否   | 最后自动保存时间          | 2024-03-10 15:25:00                      |
| created_at        | datetime     | 是   | 创建时间                  | 自动生成                                 |
| updated_at        | datetime     | 是   | 更新时间                  | 自动更新                                 |

**业务规则**：

- 一个学生对一个实验只能有一个提交记录（唯一约束）
- 学生首次进入实验页面时自动创建草稿（`draft`）
- 支持自动保存，避免数据丢失
- 提交后状态变为 `submitted`，不可再编辑
- 迟交判断：`submit_time > experiment.end_time`
- 迟交扣分：`final_score = score * (1 - late_penalty_rate)`

**状态流转**：

```
draft (草稿) → submitted (已提交) → graded (已批改)
     ↑__________________|
         (教师退回修改)
```

**索引设计**：

```sql
UNIQUE INDEX unique_experiment_student (experiment_id, student_id)
INDEX idx_student_status (student_id, submission_status)
INDEX idx_experiment_grade (experiment_id, grade_status)
INDEX idx_submit_time (submit_time)
```

### 1.2.4 实验附件实体 (CourseAttachment)

**实体说明**：学生上传的截图、录屏等附件

**字段定义**：

| 字段名         | 类型         | 必填 | 说明           | 示例值                                |
| -------------- | ------------ | ---- | -------------- | ------------------------------------- |
| id             | bigint       | 是   | 主键           | 1                                     |
| submission_id  | bigint       | 是   | 所属提交ID     | 1                                     |
| file_name      | varchar(255) | 是   | 文件名         | "step1-create-user.png"               |
| file_path      | varchar(500) | 是   | 存储路径       | "/uploads/submissions/1/..."          |
| file_size      | bigint       | 是   | 文件大小       | 156789                                |
| file_type      | varchar(50)  | 是   | 文件类型       | png / jpg / mp4 / pdf                 |
| file_category  | varchar(20)  | 是   | 分类           | screenshot / video / document / other |
| description    | varchar(500) | 否   | 附件说明       | "创建用户tom的截图"                   |
| step_number    | int          | 否   | 对应实验步骤号 | 1                                     |
| thumbnail_path | varchar(500) | 否   | 缩略图路径     | "/uploads/.../thumb.png"              |
| uploaded_by_id | int          | 是   | 上传者ID       | 101                                   |
| created_at     | datetime     | 是   | 创建时间       | 自动生成                              |

**业务规则**：

- 图片文件自动生成缩略图
- 视频文件提取第一帧作为缩略图
- 单个文件大小限制：10MB（图片）、100MB（视频）
- 学生只能删除自己上传的附件

**文件分类说明**：

- `screenshot`：操作截图
- `video`：操作录屏
- `document`：补充文档
- `other`：其他类型

**索引设计**：

```sql
INDEX idx_submission (submission_id, file_category)
```

### 1.2.5 实验评论/答疑实体 (CourseComment)

**实体说明**：实验讨论区的评论和问答

**字段定义**：

| 字段名        | 类型        | 必填 | 说明                       | 示例值                         |
| ------------- | ----------- | ---- | -------------------------- | ------------------------------ |
| id            | bigint      | 是   | 主键                       | 1                              |
| experiment_id | bigint      | 是   | 实验ID                     | 1                              |
| parent_id     | bigint      | 否   | 父评论ID（支持楼中楼）     | NULL                           |
| content       | text        | 是   | 评论内容                   | "请问chmod 755是什么意思？"    |
| content_type  | varchar(20) | 否   | 内容类型                   | text / markdown                |
| comment_type  | varchar(20) | 是   | 评论类型                   | question / answer / discussion |
| is_pinned     | boolean     | 否   | 是否置顶                   | false                          |
| is_resolved   | boolean     | 否   | 是否已解决（question类型） | false                          |
| like_count    | int         | 否   | 点赞数                     | 5                              |
| reply_count   | int         | 否   | 回复数                     | 3                              |
| author_id     | int         | 是   | 作者ID                     | 101                            |
| author_role   | varchar(20) | 是   | 作者角色                   | student / teacher              |
| created_at    | datetime    | 是   | 创建时间                   | 自动生成                       |
| updated_at    | datetime    | 是   | 更新时间                   | 自动更新                       |

**业务规则**：

- 支持二级评论（楼中楼）
- 提问类型的评论可以标记为"已解决"
- 教师可以置顶重要评论
- 教师可以删除任何评论，学生只能删除自己的

**评论类型说明**：

- `question`：提问
- `answer`：回答（针对question）
- `discussion`：一般讨论

**索引设计**：

```sql
INDEX idx_experiment_created (experiment_id, created_at)
INDEX idx_parent (parent_id)
INDEX idx_type_resolved (comment_type, is_resolved)
```

```python
import PyPDF2

def extract_pdf_text(file_path):
    """提取PDF文本内容"""
    text = ""
    with open(file_path, 'rb') as file:
        reader = PyPDF2.PdfReader(file)
```

### 1.7.2 自动保存机制

**前端实现**（Vue 3）：

```javascript
// composables/useAutoSave.js
import { ref, watch, onBeforeUnmount } from 'vue'
import { debounce } from 'lodash-es'

export function useAutoSave(saveFunction, interval = 30000) {
  const lastSaveTime = ref(null)
  const isSaving = ref(false)
  
  // 防抖保存
  const debouncedSave = debounce(async () => {
    if (isSaving.value) return
    
    try {
      isSaving.value = true
      await saveFunction()
      lastSaveTime.value = new Date()
    } catch (error) {
      console.error('自动保存失败', error)
    } finally {
      isSaving.value = false
    }
  }, 2000)
  
  // 定时保存
  const timer = setInterval(debouncedSave, interval)
  
  onBeforeUnmount(() => {
    clearInterval(timer)
  })
  
  return {
    lastSaveTime,
    isSaving,
    manualSave: debouncedSave
  }
}
```

```python
# experiment/views.py
from rest_framework.decorators import action
from rest_framework.response import Response
from .serializers import AttachmentSerializer

class SubmissionViewSet(viewsets.ModelViewSet):
    
    @action(detail=True, methods=['post'])
    def upload_attachment(self, request, pk=None):
        submission = self.get_object()
        file = request.FILES['file']
        
        # 检查文件大小
        if file.size > 10 * 1024 * 1024:  # 10MB
            return Response({'error': '文件过大'}, status=400)
        
        # 保存文件
        attachment = Attachment.objects.create(
            submission=submission,
            file=file,
            file_name=file.name,
            file_size=file.size,
            file_type=file.content_type,
            file_category=request.data.get('file_category', 'other'),
            uploaded_by=request.user
        )
        
        # 生成缩略图（异步任务）
        if attachment.file_category == 'screenshot':
            generate_thumbnail.delay(attachment.id)
        
        serializer = AttachmentSerializer(attachment)
        return Response(serializer.data, status=201)
```

```python
# experiment/tasks.py
from celery import shared_task
from PIL import Image

@shared_task
def generate_thumbnail(attachment_id):
    """生成图片缩略图"""
    attachment = Attachment.objects.get(id=attachment_id)
    
    img = Image.open(attachment.file.path)
    img.thumbnail((300, 300))
    
    thumb_path = f"thumbnails/{attachment_id}_thumb.jpg"
    img.save(thumb_path)
    
    attachment.thumbnail_path = thumb_path
    attachment.save()
```
