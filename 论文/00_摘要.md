# 摘要

随着云计算与虚拟化技术的迅猛发展，各行各业对 IT 基础设施的管理需求日益精细化和智能化。Proxmox VE (PVE) 作为一款开源、功能强大的企业级开源虚拟化平台，在中小企业以及教育机构的私有云建设中得到了广泛应用。然而，原生的 PVE 平台在多租户模型、复杂的权限管控、深度的业务场景（如教学实验）以及用户体验的现代化呈现上仍存在一定的局限性。为此，本文设计并实现了一个基于 Vue 3 与 Django 5 的 PVE 虚拟化云管平台，旨在降低 PVE 集群的运维门槛并拓展其在教务管理等垂直场景中的应用能力。

本平台采用前后端分离的现代化架构进行开发。前端层面基于 Vue 3 的组合式 API、Vite 构建机制以及 Vben Admin 框架，构建了响应迅速、数据可视化的操作管理台；并深度集成了 LogicFlow 网络拓扑工具、xterm.js 和 noVNC 提供沉浸式的终端控制交互。后端层面采用 Django 5 与 DRF 构建 RESTful API，结合 MySQL 关系型数据库完成数据持久化，通过 PVE REST API 与 SSH 实现了基础设施的深度调度。同时，采用 ASGI 异步服务器与 WebSocket 协议，实现对实例控制台的实时对接与双向通信。

系统重点实现了四大核心功能：一是全生命周期的虚拟机与容器集群管理，支持基础监控与网络资源的拓扑可视化分配；二是构建了基于 RBAC 模型的组织架构及多级细粒度权限控制体系，保障平台安全性并配备接口级操作审计流水；三是面向教育场景的实验教学双角色协同管理，为教师及学生提供在线实验环境的流式分发与 Markdown 实验报告编辑体验；四是创新性地融合了大语言模型服务，以 RAG 技术赋能系统的智能运维问答。

经过充分的黑盒与白盒测试以及高并发通信性能测试，系统的各项功能模块运作正常，满足设计初期的非功能性要求，具备高可用性和良好的扩展性，为私有云平台的低成本搭建和智能化运维提供了可靠的解决方案。

**关键词**：虚拟化云平台；Proxmox VE；Vue 3；Django；实验管理；大语言模型；RBAC

# Abstract

With the rapid development of cloud computing and virtualization technologies, the demand for refined and intelligent management of IT infrastructure in various industries is increasing. Proxmox VE (PVE), as an open-source and powerful enterprise-level virtualization platform, has been widely applied in the construction of private clouds for small and medium-sized enterprises and educational institutions. However, the native PVE platform still has certain limitations in multi-tenant models, complex permission management, deep business scenarios (such as teaching experiments), and the modern presentation of user experiences. Therefore, this paper designs and implements a PVE virtualization cloud management platform based on Vue 3 and Django 5, aiming to lower the operation and maintenance threshold of PVE clusters and expand its application capabilities in vertical scenarios such as educational administration.

The platform is developed using a modern architecture with separated front-end and back-end. At the front-end level, based on the composition API of Vue 3, the Vite build mechanism, and the Vben Admin framework, a responsive and data-visualized operation management console is constructed. It deeply integrates the LogicFlow network topology tool, xterm.js, and noVNC to provide immersive terminal control interactions. At the back-end level, Django 5 and DRF are used to build RESTful APIs, combined with a MySQL relational database to complete data persistence. Deep scheduling of the infrastructure is achieved through the PVE REST API and SSH. Meanwhile, the ASGI asynchronous server and WebSocket protocol are adopted to realize real-time connection and two-way communication with instance consoles.

The system focuses on four core functions: First, the full life-cycle management of virtual machine and container clusters, supporting basic monitoring and topological visual allocation of network resources; Second, the construction of an organizational structure and a multi-level fine-grained permission control system based on the RBAC model, ensuring platform security and equipped with interface-level operation audit pipelines; Third, the dual-role collaborative management of experimental teaching for educational scenarios, providing teachers and students with streaming distribution of online experimental environments and a Markdown experimental report editing experience; Fourth, the innovative integration of large language model services, empowering intelligent operation and maintenance Q&A of the system with RAG technology.

Through sufficient black-box and white-box testing, as well as high-concurrency communication performance testing, the various functional modules of the system operate normally, meeting the non-functional requirements at the initial stage of design. It possesses high availability and good scalability, providing a reliable solution for the low-cost construction and intelligent operation and maintenance of private cloud platforms.

**Keywords**: Virtualization Cloud Platform; Proxmox VE; Vue 3; Django; Experiment Management; Large Language Model; RBAC
