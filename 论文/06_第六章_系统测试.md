# 第六章 系统测试

## 6.1 测试目的

本章对基于 Vue 3 与 Django 5 的 PVE 虚拟化管理系统进行系统性功能测试，旨在验证系统各模块的功能完整性与正确性，确认系统实现满足第三章需求分析中提出的各项功能性需求。测试覆盖系统登录与权限管理、仪表盘数据展示、PVE 资源管理、实验教学、AI 助手以及系统管理与审计共六大核心模块，通过设计典型测试用例，逐项验证系统在正常输入条件下的功能表现，保证系统在交付前达到预期的设计目标与质量标准。

## 6.2 测试环境

**硬件环境方面**，测试部署于 Proxmox VE 物理服务器上创建的一个 LXC 容器实例，该容器配置为 4 核 CPU、8 GB 内存与 100 GB 磁盘，运行 ubuntu操作系统，为系统后端服务、数据库及前端静态文件提供统一的运行环境。

**软件环境方面**，后端采用 Python 3.12 运行，Web 框架为 Django 5.0，配合 Django REST Framework 提供 RESTful API 服务，Django Channels 与 Daphne ASGI 服务器支持 WebSocket 实时通信；前端基于 Vue 3 与 Vben Admin 框架构建，由 Nginx 进行静态文件托管；数据存储层使用 MySQL 8.0 作为关系型数据库；测试所用客户端为 Chrome 浏览器。

**网络环境方面**，通过 frp（Fast Reverse Proxy）内网穿透工具，将 LXC 容器内的各服务端口映射至公网服务器的指定端口，可通过公网域名或IP直接访问系统前端及后端接口，模拟真实用户的使用场景。

## 6.3 功能测试

## 6.4 本章小结

本章对 PVE 虚拟化管理系统的六大功能模块进行了系统性功能测试，测试环境基于 LXC 容器部署并通过 frp 内网穿透对外提供访问，贴近真实使用场景。测试内容覆盖系统登录与权限管理、仪表盘数据展示、PVE 资源管理、实验教学、AI 助手以及系统管理与审计模块，共设计并执行了 39 条功能测试用例，全部测试结果均符合预期，无功能缺陷。测试结果表明，系统各模块功能完整，交互逻辑正确，数据处理准确，安全控制有效，系统整体达到了第三章需求分析所规定的各项功能性设计目标，具备正式部署与使用的条件。
